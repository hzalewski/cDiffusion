# cDiffusion: Non-Linear Dimensionality Reduction via Diffusion Maps

Implements memory-efficient, non-linear dimensionality reduction using
Diffusion Maps. Features an automated engine dispatch that dynamically
switches between dense exact evaluations for small datasets and a highly
optimized, multi-threaded C-engine using Max-Heaps and randomized
Singular Value Decomposition (rSVD) for large-scale data.
